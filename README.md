# Emergency Detection App
An advanced AI-powered health and safety monitoring system designed to detect life-threatening situations in real-time. By leveraging computer vision and on-device machine learning, the app identifies falls, fatigue, and potential health emergencies, providing instant SOS alerts to caregivers.

## Features
- Fall & Posture Detection
- Drowsiness & Fatigue Tracking
- Early Stroke Symptom Detection
- Smart SOS Emergency System
- Real-time Diagnostic Dashboard


Language: Kotlin
- UI Framework: Jetpack Compose (Modern declarative UI)
- Camera: Android Camera
- AI Engine: Google MediaPipe
- Architecture: MVVM (Model-View-ViewModel)
- Networking: Retrofit (for Telegram API communication)
- Concurrency: Kotlin Coroutines & Flow
